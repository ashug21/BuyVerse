Tech Stack: Next.js, React, Node.js, Express, MongoDB Atlas, Razorpay (UPI)

Designed and developed a full-stack e-commerce platform with product browsing, cart management, address
handling, order placement, and secure UPI payment integration. User can also leave reviews once they are logged in 
Implemented dynamic routing, RESTful APIs,Next auth, localStorage-based cart persistence, responsive UI components, 
and optimized checkout flow. Deployed on Vercel. Also contains a full admin dashboard where admin can remove users, 
create users , also see all the reviews, orders , and addresses available. Moreover it also has total earnings
dashboard page which shows list of payments made.
